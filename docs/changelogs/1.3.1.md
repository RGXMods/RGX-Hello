# RGX-Hello 1.3.1

Released 2026-08-23. Requires RGX-Framework v2.7.4.

- Startup output is now one metadata-derived `RGX:LoginMessage` line showing
  both RGX-Hello and RGX-Framework versions.
- The startup line obeys the framework-owned global login-message preference.
- RGXVisual diagnostic output uses the standard framework formatter and no
  longer prints an independent login line.
- All six flavor TOCs declare RGX-Hello 1.3.1 and Framework minimum 2.7.4.
