# RGX-Hello v1.3.4

  X-Curse-Project-ID 1596350, so the in-house publisher uploads each tagged
  release to the approved CurseForge project.

  metadata as a plain string form field, as the Wago API requires.
- Require RGX-Framework 2.7.17 or newer, in lockstep with the secure minimap
  stable release.

No Lua, XML, Interface or behavior changes; the runtime is unchanged from
v1.3.3.
